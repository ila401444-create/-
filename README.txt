1) Создай репозиторий на GitHub и загрузи в него ВСЕ файлы из этой папки (включая папку .github).
2) Вкладка Actions -> Build APK -> дождись зелёной галочки (5-10 минут).
3) Внутри запуска внизу раздел Artifacts -> coder-sim-apk -> скачай, распакуй, установи app-debug.apk.
4) Адрес сервера уже вписан в игру, вводить ничего не нужно: просто войди или зарегистрируйся.
Игру можно менять в www/index.html: после правки сделай commit, и APK соберётся заново.
