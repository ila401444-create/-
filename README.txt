ЛАУНЧЕР. APK собирается один раз и больше не нужен для обновлений игры.

1) Залей ВСЕ файлы этой папки в репозиторий GitHub (включая .github и www/audio).
2) Actions -> Build APK -> скачай app-debug.apk из Artifacts и установи.
3) Дальше игру обновляешь ТОЛЬКО на хостинге: замени coder.html.
   Лаунчер при запуске сверяет версию, скачивает новую (сжато) и по кнопке «Играть» открывает игру.
   Новости на экране лаунчера: админ-панель -> Сервер -> «Новости лаунчера».
   Нет интернета -> «Отсутствует подключение к интернету» + «Повторить» и «Играть офлайн».

Адрес сервера прописан в www/index.html (строка DEF). Пересобирать APK нужно только если меняется
сам лаунчер (www/index.html), музыка (www/audio), запасная копия (www/game.html) или адрес сервера.


Название: CoderSim. Пакет Android: com.codersim.game (задан в capacitor.config.json).
ВАЖНО: из-за нового имени пакета это новое приложение, старое com.coder.sim надо удалить вручную.
Иконка: три картинки в папке icon/, все размеры создаются автоматически при сборке (icon/make.py).
